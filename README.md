# SPIN

Official repository for **Student-Informed Prompt Distillation for Vision-Language Models**.

## Datasets

All datasets used in this work are publicly available benchmark datasets.
No new dataset was collected or created.

### Base-to-Novel Generalisation and Cross-Dataset Transfer
- ImageNet
- Caltech101
- OxfordPets
- StanfordCars
- Flowers102
- Food101
- FGVCAircraft
- SUN397
- DTD
- EuroSAT
- UCF101

### Domain Generalisation
- ImageNet-V2
- ImageNet-Sketch
- ImageNet-A
- ImageNet-R

The datasets are available from their respective official sources and are
subject to their original licenses and terms of use.
